# Algorithms and Data Structures

![CI](https://github.com/me-rayaaa/algorithms-and-data-structures/actions/workflows/ci.yml/badge.svg)

Учебный проект: реализации базовых структур данных и алгоритмов сортировки на Python с юнит-тестами и CI.

## Что реализовано

### Структуры данных (`structures.py`)

- **MyArray** — динамический массив
- **LinkedList** — односвязный список
- **Deque** — двусторонняя очередь
- **AVLTree** — самобалансирующееся бинарное дерево поиска

### Алгоритмы сортировки (`sortings.py`)

- **Bubble Sort** — сортировка пузырьком, O(n²)
- **Quick Sort** — быстрая сортировка, O(n log n) в среднем

## Тесты

Тесты написаны на `pytest`. Покрывают:

- базовые операции каждой структуры (добавление, удаление, обход);
- корректность сортировок, включая пустые массивы и дубликаты;
- балансировку AVL-дерева после серии вставок.
